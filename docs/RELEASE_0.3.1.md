# DueCase 0.3.1

Fixes the redundant bottom safe-area in Home/chat and gives the root navigation sole ownership of system insets. Chat scrolls to the latest message after viewport/content changes while preserving older-message reading; Android uses native window resizing instead of a second keyboard height subtraction. Navigation hides while the keyboard is open.

Home bell opens the six latest notifications, with unread indicators, retry, close/outside dismissal and See all. Opening a notification marks it read and navigates to its relevant section. Specific historical-entity highlighting remains outside this release.

Settings has dedicated Profile, Security, Family, Notifications, Subscription, Privacy and Help pages. Profile changes update both user/parent names. Password change verifies current password, enforces the registration policy, rate-limits attempts, consumes reset challenges and revokes old tokens; a replacement token keeps this device signed in. Other-session revocation also rotates tokens. Push registration is cleared on revocation and retried for the current device.

Push preferences are saved per user and applied on the server before delivery. In-app activity remains visible. Missing Firebase configuration is detected at build time and clearly reported; no permission prompt or failed token attempt is made for an unconfigured Android build. Email and push provider setup remain intentionally deferred.

Profile JSON export includes only explicit personal-profile fields and preferences, never authentication secrets. Shared records remain available through the family Dossier. Account deletion retains its confirmation and shared-history policy. Help prepares a shareable issue template without automatically sending messages. Family page lists connected parents and links to children.

Billing/restore-purchase integration and final legal documents remain explicitly unavailable pending external setup/content. No fabricated purchase or legal links are presented. Profile export is not a complete attachment/history export.

Validation: 10 integration tests pass on disposable PGlite, including profile/preference isolation, safe export, wrong/mismatched password rejection, password rotation and session revocation. Backend and frontend TypeScript pass. Physical Android keyboard/scroll and two-device push delivery still require device testing. Native APK is generated by GitHub Actions.
